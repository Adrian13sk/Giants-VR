# Giants: Citizen Kabuto VR

An ambitious community-driven project exploring a native, standalone VR port of *Giants: Citizen Kabuto* to the Meta Quest 2.

The project aims to bring the iconic world of Giants into immersive virtual reality, combining original game assets, environments, and animations with VR rendering, head tracking, and motion-controller support.

The long-term goal is to preserve the original game's distinctive characters, gameplay, combat, missions, and environments in a fully standalone experience that runs directly on Quest hardware—without PC streaming.

**Project goals**
- Native standalone Android/ARM64 support.
- Immersive stereoscopic VR and head tracking.
- Original game models, maps, and animations.
- VR-compatible camera systems and Quest Touch controls.
- Original gameplay, AI, combat, and mission integration.
- Performance optimization for Meta Quest 2.
- An installable APK and reproducible development workflow.

**Status:** Experimental development. The project is evolving from a working VR development demo toward a more complete playable port. Features and compatibility are subject to ongoing development and testing.

This is an independent, unofficial project and is not affiliated with or endorsed by the original game's developers or publisher. Original game assets remain the property of their respective rights holders.
